# Collection App — PWA آفلاین وصول مطالبات

راهنمای فارسی کامل: `docs/راهنما.md`

شروع سریع:
1. `node tools/make-users.mjs --generate 50` سپس `node tools/make-users.mjs`
2. `server/apps-script.js` را در Google Apps Script دیپلوی و آدرس/توکن را در `config/app.config.js` بگذارید
3. `node tools/build.mjs` و آپلود روی هاست HTTPS
