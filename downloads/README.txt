هر فایلی (PDF، Word، Excel، عکس، ...) داخل همین پوشه بگذارید،
در بخش «دانلودها»ی برنامه با همان نام فایل نمایش داده می‌شود.

بعد از گذاشتن فایل:
  • اگر پروژه روی GitHub Pages است و فایل Action همراه پروژه فعال است، خودکار فهرست به‌روز می‌شود.
  • در غیر این صورت دستور   node tools/build.mjs   را اجرا کنید و پروژه را دوباره روی هاست بگذارید.
